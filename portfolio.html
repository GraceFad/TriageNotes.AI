01 — Problem & solution

Documentation slows down care.
AI can change that.

Nurses spend significant time on manual documentation during triage — time that should go to patients. TriageNotes.AI eliminates that friction with a single voice recording.

The problem

  • ✕Manual note-taking is slow and error-prone
  • ✕Documentation happens after the encounter, from memory
  • ✕Inconsistent triage priority assignment
  • ✕Nurses carry documentation burden throughout their shift

The solution

  • ✓One-tap recording captures the encounter live
  • ✓Instant structured EHR output on completion
  • ✓Automatic ESI Level 1–5 triage classification
  • ✓Transcript retained for review and audit

02 — Key features

Everything the care team needs, in seconds.

🎙️

Live audio recording

One-tap recording with a real-time frequency visualizer. Captures the encounter via browser microphone using the Web Audio API.

🧠

AI transcription

Single Gemini Flash API call simultaneously transcribes audio and extracts structured EHR fields — no two-step pipeline.

📋

EHR data extraction

Auto-populates chief complaint, HPI, vitals, allergies, medications, past medical history, and recommended action.

🚦

ESI triage classification

Assigns Emergency Severity Index Level 1–5 based on the encounter, color-coded for immediate clinical clarity.

📝

Verbatim transcript

Full audio transcript retained alongside the structured note for review, correction, and clinical audit.

⚡

Structured JSON schema

Gemini responds via strict response schema — consistent, parseable, reliable output every time.

05 — Roadmap

What's been built, what's next.

Phase 1 — Complete

Audio recording pipeline

MediaRecorder integration, real-time frequency visualizer, recording timer, and microphone permission handling.

Phase 2 — Complete

Gemini transcription + EHR extraction

Single-call Gemini Flash integration with strict JSON response schema for consistent, structured EHR output.

Phase 3 — Complete

ESI triage classification UI

Color-coded Level 1–5 triage badge, vitals grid, transcript toggle, and full EHR card display.

Phase 4 — Planned

PDF export

One-click export of the generated EHR note as a printable PDF for handoff and record-keeping.

Phase 5 — Future

FHIR-compatible EHR integration

Export structured data to Epic and other common EHR systems via HL7 FHIR standards.
